# Supply Chain Analytics Dashboard

## About the Project

This project focuses on analyzing supply chain data and presenting the results through dashboards created using Microsoft Excel, Python, and Power BI.

The project covers different areas of supply chain operations, including purchasing, sales, inventory, warehouses, deliveries, and transportation costs.

We worked on this project to understand how data can be used to track business performance, analyze different trends, and get useful insights from supply chain records.

## Project Objectives

Analyze purchasing, sales, inventory, and transportation costs.

Track closing stock and damaged quantities.

Understand monthly order trends.

Compare stock levels and capacity across warehouses.

Review delivery statuses and on-time delivery performance.

Analyze sales and purchasing activities.

Present important information through dashboards using different data analysis tools.

## Tools and Technologies

- Python – Data analysis and data visualization.
- Pandas – Data manipulation and data cleaning.
- NumPy – Numerical operations and calculations.
- Matplotlib and Seaborn – Creating charts and visualizations.
- Microsoft Excel – Data analysis and dashboard creation.
- Power Query – Data cleaning and preparation.
- Pivot Tables – Summarizing and analyzing data.
- Microsoft Power BI – Dashboard creation and data visualization.
- DAX – Creating calculated measures and KPIs.

## Data Preparation and Analysis

The project uses different datasets related to suppliers, products, warehouses, customers, purchase orders, inventory, sales orders, shipments, deliveries, and transportation.

We worked with these datasets to understand the structure of the data, prepare it for analysis, and calculate important business metrics.

The analysis mainly focuses on comparing costs, reviewing inventory distribution, understanding warehouse capacity, monitoring delivery performance, and analyzing sales and order trends.
