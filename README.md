## About the Project

This project focuses on analyzing supply chain data and presenting the results through an interactive Excel dashboard. The main idea was to bring important information about purchasing, sales, inventory, warehouses, deliveries, and transportation costs into one place.

Instead of checking different records manually, the dashboard makes it easier to get an overview of supply chain activities using KPI cards, charts, and filters.

I created this project to practice data analysis, data visualization, and the use of Excel for reporting and business analysis.

## Project Objectives

Analyze purchasing, sales, inventory, and transportation costs.

Track closing stock and damaged quantities.

Understand monthly order trends.

Compare stock and capacity across warehouses.

Review delivery statuses and on-time delivery performance.

Present key information in a single dashboard for easier analysis.

## Tools and Technologies

- Microsoft Excel – Data analysis and dashboard creation

- Power Query – Data cleaning and preparation

- Pivot Tables – Summarizing and analyzing data

- Charts and KPI – Visualizing data and analyse results

## Dashboard Overview

The dashboard includes eight KPI cards:

- Total Purchase Cost

- Total Sales Cost

- Total Inventory Cost

- Total Transportation Cost

- Total Closing Stock

- Total Damaged Quantity

- Total Deliveries

- On-Time Delivery Percentage

It also contains charts for inventory value by category, monthly order trends, closing stock by warehouse, warehouse capacity, delivery status distribution, transportation cost by mode, sales by category, and customer type distribution.

These visualizations help compare different parts of the supply chain and make the information easier to understand.

## Data Preparation and Analysis

The data was organized and prepared before creating the dashboard. Power Query and Excel analysis features were used as part of the data preparation and reporting process.

The analysis focuses on comparing costs, reviewing inventory distribution, monitoring delivery statuses, and understanding order and sales patterns. The dashboard brings these results together so that users can review the main measures without going through the entire dataset.
